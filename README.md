# Life Changing Task — бот + Telegram Mini App

Это следующий шаг после обычного бота: тот же трекер (9 задач, 26 недель),
но теперь ещё и с красивым экраном внутри Telegram (Mini App), который
открывается по кнопке вместо сообщений.

## Почему это ОДИН проект, а не два

Mini App — это веб-страница, а Telegram требует, чтобы она была на
настоящем сайте с HTTPS (не с твоего компьютера напрямую). Раз всё равно
нужен постоянно работающий сервер — я объединил его с самим ботом. Теперь
это один файл `app.py`, который:

- отдаёт саму страничку трекера (папка `static/`)
- отдаёт для неё данные через маленький API (`/api/state`, `/api/checkin`)
- одновременно работает как обычный Telegram-бот (те же команды, что были)

Это заодно решает и вопрос "чтобы бот работал 24/7" — раз мы всё равно
размещаем это на сервере.

## Файлы

- `app.py` — всё: и бот, и веб-сервер
- `static/index.html` — сама страница Mini App (оформлена в стиле твоего
  плаката — чёрный/кремовый, диагональные клетки как в оригинале)
- `requirements.txt` — какие библиотеки нужны

## Локальная проверка (без реального деплоя)

Можно проверить, что бот вообще запускается, у себя на компьютере — так же,
как раньше:

```
pip install -r requirements.txt
set TELEGRAM_BOT_TOKEN=твой_токен
python app.py
```

Команды `/start`, `/tasks`, `/today`, `/progress`, `/settime` будут
работать сразу. Но кнопка "Открыть трекер" (Mini App) работать не будет,
пока не выставлена переменная `MINI_APP_URL` — а её можно получить только
после реального деплоя (см. ниже), потому что Telegram не откроет страницу
с твоего домашнего компьютера.

## Деплой на реальный хостинг (обязательно для Mini App)

Тебе нужен хостинг, который:
1. Даёт постоянный публичный адрес с HTTPS
2. Умеет запускать Python-процесс, слушающий порт из переменной `PORT`

Подойдёт почти любой современный "PaaS"-хостинг (Render, Railway, Fly.io
и подобные) — принцип везде одинаковый:

1. Зарегистрируйся на выбранной платформе
2. Создай новый веб-сервис, подключи туда эти файлы (через их интерфейс
   загрузки файлов или через GitHub — обычно проще всего сначала загрузить
   папку на GitHub, а потом подключить репозиторий к хостингу)
3. Команда запуска (Start command): `python app.py`
4. Задай переменные окружения (Environment variables) в настройках сервиса:
   - `TELEGRAM_BOT_TOKEN` — твой токен от BotFather
   - `PORT` — обычно хостинг сам подставляет её, но если нет — впиши 8000
5. После первого деплоя хостинг даст тебе публичный адрес вида
   `https://твой-проект.онлайн-адрес.app`
6. Добавь ещё одну переменную окружения:
   - `MINI_APP_URL` — вставь туда именно этот адрес (с `https://` в начале)
7. Перезапусти сервис (обычно кнопка "Redeploy" или "Restart")

Условия и интерфейс у хостингов часто меняются, поэтому конкретные
кнопки/названия разделов могут отличаться от того, что я описал — если
что-то не находится на экране, пришли скриншот, разберёмся по месту.

### Регистрация Mini App в самом Telegram (через BotFather)

Это отдельный шаг — просто указать Telegram, что у бота есть Mini App:

1. Напиши **@BotFather** команду `/mybots`
2. Выбери своего бота
3. **Bot Settings → Menu Button → Configure Menu Button**
4. Вставь тот же адрес (`MINI_APP_URL`) и название кнопки, например
   "Открыть трекер"

После этого рядом с полем ввода сообщения в чате с ботом появится кнопка,
которая тоже открывает Mini App — не только через `/app` или `/start`.

## Как это выглядит внутри

- Вкладка **"Сегодня"** — список задач с диагональными чекбоксами
  (как ячейки в твоей исходной таблице), тап переключает, кнопка
  "Сохранить" внизу фиксирует день
- Вкладка **"Прогресс"** — на какой ты неделе, сколько идеальных дней,
  проценты по каждой задаче, и мини-карта всех прошедших недель
  (тёмная клетка = задача выполнялась чаще)
- Вкладка **"Мои задачи"** — список задач можно редактировать: изменить
  текст, эмодзи и пояснение (значок ✎), удалить (значок ✕), или добавить
  свою через кнопку "+ Добавить задачу". У каждого пользователя список
  полностью свой — начинается с 9 задач по умолчанию (как в исходной
  таблице), максимум 10 задач одновременно.

## Если что-то не работает

- Кнопка "Открыть трекер" не появляется → проверь, что переменная
  `MINI_APP_URL` задана на хостинге и сервис перезапущен после этого
- Страница открывается, но пустая/ошибка → скорее всего открыл её не
  через кнопку в боте, а по прямой ссылке в браузере — Mini App работает
  только внутри Telegram, потому что ему нужны данные о пользователе,
  которые Telegram передаёт автоматически
- Изменения в `static/index.html` не видны → после любого изменения файлов
  нужен новый деплой на хостинге, простое сохранение файла на компьютере
  ничего не меняет на сервере
